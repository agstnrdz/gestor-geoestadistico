Sobre el proyecto

El sistema de gestión de datos geoestadísticos es una herramienta interna del Departamento de Geoestadísticas para centralizar, visualizar y distribuir información georreferenciada del territorio municipal.

history_edu Origen y motivación

Actualmente se combinan herramientas de Google Drive y Google Sheets que resultan ineficientes para el volumen y interoperabilidad de datos tabulares dentro de la dirección. La plataforma busca modernizar y complejizar los procesos de gestión de base de datos georreferenciados.

El desarrollo se lleva a cabo en la red local y eventualmente se publican actualizaciones mediante el repositorio público del sitio de GitHub Pages.

account_balance Contexto institucional

Unidad ejecutora

Departamento de Geoestadísticas, Dirección General de Modernización e Investigación Territorial

Dependencia

Municipio de Comodoro Rivadavia, Provincia del Chubut, Argentina

flag Objetivos

  • Centralizar los datos georreferenciados producidos por el departamento en una plataforma de acceso interno.
  • Reemplazar herramientas externas (Google Drive, Google Sheets, UMap) por una solución institucional.
  • Facilitar la visualización cartográfica de capas temáticas sin dependencia de servicios de terceros.
  • Documentar los datasets producidos mediante un catálogo de metadatos estandarizado.
